# Craftly UI Design Documentation

## Design Overview
The Craftly user interface is designed to be clean, minimalist, and conversion-focused. It leverages the brand identity (Indigo, Emerald, Amber) to create a professional yet creative atmosphere. The layout is optimized for high-quality digital product displays.

## Key UI Components

### 1. Landing Page
- **Hero Section:** Bold headline using Inter (Bold), a clear Call to Action (CTA) button in Indigo (#6366F1), and a background that highlights digital creativity.
- **Featured Products:** A 3 or 4-column grid of product cards with subtle hover effects.
- **Value Proposition:** Icon-based sections explaining the benefits for both buyers and sellers.
- **Mockup:** [landing-page.png](/home/team/shared/ui-mockups/landing-page.png)

### 2. Product Catalog
- **Grid Layout:** Flexible grid showing product thumbnails, titles, prices, and seller ratings.
- **Filters:** A sidebar or top bar allowing users to filter by category (Templates, Graphics, Fonts, etc.), price range, and rating.
- **Search:** A prominent search bar at the top of the page.
- **Mockup:** [product-catalog.png](/home/team/shared/ui-mockups/product-catalog.png)

### 3. Product Detail Page
- **Hero Image:** High-resolution preview of the digital product.
- **Purchase Box:** Price, rating, and a prominent 'Add to Cart' button pinned to the right (desktop) or bottom (mobile).
- **Tabs/Sections:** Product description, features, requirements, and reviews.
- **Mockup:** [product-detail.png](/home/team/shared/ui-mockups/product-detail.png)

### 4. Shopping Cart
- **List View:** Items listed with thumbnails, titles, prices, and quantity selectors.
- **Summary:** Clear subtotal display and a prominent 'Proceed to Checkout' button.
- **Mockup:** [shopping-cart.png](/home/team/shared/ui-mockups/shopping-cart.png)

### 5. Checkout Flow
- **Simplicity:** A distraction-free checkout experience.
- **Order Summary:** Always visible to keep the user informed.
- **Trust Elements:** Secure payment icons and clear breakdown of costs.
- **Mockup:** [checkout-flow.png](/home/team/shared/ui-mockups/checkout-flow.png)

### 6. Seller Dashboard
- **Navigation:** Vertical sidebar for easy access to management tools.
- **Overview:** Top-level KPIs (Revenue, Sales, Product Count).
- **Chart:** A simple line chart showing sales trends over time.
- **Action Buttons:** Clear buttons to 'Add New Product'.
- **Mockup:** [seller-dashboard.png](/home/team/shared/ui-mockups/seller-dashboard.png)

### 7. User Account Page
- **Profile:** Basic user info and profile settings.
- **Order History:** Table view of past purchases.
- **Saved Items:** A grid or list of products the user has favorited.
- **Mockup:** [user-account.png](/home/team/shared/ui-mockups/user-account.png)

## Design System Notes
- **Spacing:** Use a 4px or 8px grid for consistent margins and padding.
- **Shadows:** Use soft, subtle shadows to create depth without clutter.
- **Buttons:**
  - **Primary:** Solid Indigo (#6366F1) with white text.
  - **Secondary:** Outline Indigo or light gray background.
  - **Success:** Solid Emerald (#10B981) for completion/success states.
- **Icons:** Use consistent line-weight icons (e.g., Lucide or Heroicons).
